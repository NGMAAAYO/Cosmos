# Designed competitive maps

六张正式地图全部为双人、双轴对称地图，并由`utils/designed_maps.py`确定性生成。脚本不导入`random`；细微地形变化来自镜像后的谐波函数，因此相同版本总会得到完全相同的JSON。

## 共同数值约束

- 自然地形以太限制在`[0.2, 0.95]`；只有刻意设计的黑洞隔断使用`0.0001`。
- 所有黑洞隔断均保留至少两条独立路线和多个不少于三格宽的换线口，避免单个实体永久封锁地图。
- 初始星球的连续近似建造吞吐为`aether / 2`。同类型的单星球图与多星球图保持相同的全队初始吞吐：决斗`0.32`、中心`0.28`、分路`0.30`次/回合。
- 单目标、无侦查增益时，占领`N`能量中立星球需要战列舰防护满足`D - 10 > N`。因此中心图的`75`能量目标至少需要`86`防护，分路图的`100`能量目标至少需要`111`防护。
- 下表到达时间包含战斗单位初始`10`冷却，并使用实际以太密度做最短路计算；目标判定为进入战列舰平方行动半径`9`。

## 地图引导

### Fang

中央三格宽的`0.78`高速脊线制造最短正面交战路径，两条`0.66`斜向带允许侧翼汇入。无墙、无中立目标，使侦查、集结和过载交换成为唯一焦点。单星球`0.64`以太提高早期出兵频率，适合短图直接攻防。

### Bastion

双方各有两颗`0.32`出生星球，总建造吞吐与Fang一致，但初始资源与自然产能更高。两组镜像黑洞堡垒将战线分成顶部、中央和底部三条宽通路；中央`0.72`、边路`0.68`，鼓励正面主攻与上下换线，而不是围绕资源点游走。

### Crown

唯一`75`能量星球位于地图中心，其所在竞技场以太为`0.72`，周围核心区达到`0.84`。两格厚的方形黑洞冠冕留下东、西、南、北四个三格宽入口，使抢占中心有明确收益，同时保留绕侧和反包围空间。

### Crucible

双方各有两颗`0.28`出生星球，总初始建造吞吐与Crown相同。中央`75`能量星球位于`0.82`竞技场内，外侧黑洞环有四个五格宽入口；`0.70`对角线和`0.64`十字带将四颗出生星球引向同一熔炉，但大型尺度使集结、佯动和矿船经济仍有时间展开。

### Fork

两颗`100`能量星球在中央轴线上上下镜像。`0.78`V形高速带从双方出生点分叉至两个目标；中央三段黑洞隔断之间保留三个换线口。玩家必须在集中夺取一个目标、分兵争夺两个目标和从中部佯攻后换线之间选择。

### Delta

双方各有上下两颗`0.30`出生星球，总建造吞吐与Fork一致。上下`0.80`主航道各通往一颗`100`能量星球，中央`0.62`航道用于快速佯攻与支援；两组镜像黑洞带各有三个换线口，使初始分路不会永久锁定后续部署。
